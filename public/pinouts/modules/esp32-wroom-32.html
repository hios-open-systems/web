Información de Pines

Input Only (IO34-39)

Los pines IO34, IO35, IO36, IO39 son solo entrada. No tienen resistencias pull-up/down internas. Ideal para sensores analógicos.

Strapping Pins

IO0, IO2, IO5, IO12, IO15 afectan el boot. Evitar conectar cargas durante el arranque. IO0 bajo = modo flash.

ADC durante WiFi

ADC2 (IO0,2,4,12-15,25-27) no funciona cuando WiFi está activo. Usar ADC1 (IO32-36,39) para lecturas confiables.

I2C Default

I2C por defecto: IO21 (SDA) y IO22 (SCL). Cualquier GPIO puede ser I2C vía software.
