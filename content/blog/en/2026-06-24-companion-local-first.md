PAD can send shortcuts over USB or Bluetooth without knowing the computer’s actual state. For example, sending a volume command does not automatically tell it the resulting volume level.

The companion adds that information channel. It is a Node and TypeScript program that runs on the computer, queries the available data and sends it to PAD over the local network.

## What information it sends

The program uses `POST /api/state` at an interval configured through `pollMs`. It can send volume, microphone status, and CPU and GPU load or temperature, depending on the available providers and sensors.

The configuration lets you choose which fields to send. A missing value should not be interpreted as a measurement of zero: the computer may not expose it, or the program may have failed to retrieve it.

## Which functions require the companion

| Function | Requirement |
|---|---|
| Keyboard, mouse and media shortcuts | HID connection over USB or BLE. |
| Actual computer status on the display | Companion and network connection. |
| Toggle the global microphone mute | Companion and operating system support. |
| Web editor and interface mirror | Configured and reachable companion. |

The firmware returns to its estimated state when it stops receiving recent information. That state represents PAD’s actions, not confirmation from the operating system.

## Commands in the other direction

PAD can request an action from the companion in the response to `POST /api/state`. The companion processes it and reports the resulting state in subsequent updates.

Global microphone mute is different from sending a shortcut to an application. Meeting and camera controls depend on the active application and the configured shortcuts.

## Getting it ready

Follow the companion README to build it. Configure PAD’s address, the token generated by the firmware and the polling interval. Both devices must be able to communicate over the network.

Providers are implemented for Windows and Linux. macOS support is still pending. The instructions include automatic startup options for Windows and a user service for Linux.

Before considering setup complete, check which data reaches the display and what happens when you stop the companion. This helps distinguish HID actions from functions that depend on the connection.
